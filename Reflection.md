# Reflection

## Reflection 1 - How did AI support the documentation process?

AI helped me understand how to organize technical documentation using Markdown. It suggested a clear structure for the README, including sections such as Overview, Installation, Usage, Example Code, and License. It also helped me organize the R Markdown document into Purpose, Inputs, Processing, Outputs, and Conclusion. This made the documentation process easier to understand and more organized. However, I did not rely only on the AI-generated content. I reviewed the suggestions and adapted them to my actual R project.

## Reflection 2 - How did verification and refinement improve the AI-generated content?

Verification was important because AI-generated content should not automatically be assumed to be correct. I reviewed the Markdown structure and checked that the code matched my actual `sales_analysis.R` script. I ran the R script in RStudio and confirmed that the synthetic dataset, total sales calculations, and summary statistics worked correctly. I also used the Knit function in RStudio to verify that the `.Rmd` file rendered successfully. Refining and testing the AI suggestions helped make the final documentation clearer, more accurate, and appropriate for the project.

## Reflection 3 - What did I learn about the responsible use of AI?

I learned that AI can be useful for generating ideas, improving organization, and helping with Markdown formatting, but human verification is still necessary. AI can make mistakes or suggest information that does not accurately represent a project. For this reason, I checked the generated content, tested the R code, and reviewed the final documentation. I also disclosed the use of ChatGPT and documented the main prompts used during the assignment. This experience showed me that AI is most useful as an assistant while the student remains responsible for the final work.
